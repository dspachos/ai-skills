Skills

Grouped by when you reach for them. The collection starts small; it grows when a process proves itself.

What is a skill?

A skill is a folder with a SKILL.md file inside. The frontmatter names the skill and tells your agent when to use it. The body is the process: the steps, the commands, and the judgment you want applied. Type the slash command, and the agent follows it.

Why plain files?

Skills are Markdown and scripts you can read. Nothing runs at install time. When you disagree with a step, you edit the file — not a config you cannot see.

Which agents?

Skills are an open format, not a platform. Any agent that reads SKILL.md works.

  • Copilot
  • Amp
  • pi
